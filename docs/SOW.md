# Statement of Work (SOW) - 古都茶房ウェブサイト開発

## プロジェクト概要
本プロジェクトは、架空のカフェ「古都茶房」のシングルページアプリケーション（SPA）を開発し、静的サイトとしてビルドすることを目的とします。

## スコープ
React + TypeScript + Vite + Tailwind CSSを使用して、レスポンシブ対応の静的ウェブサイトを構築します。

## 成果物
- ソースコード一式
- ビルド済み静的ファイル（distフォルダ）
- 実装ドキュメント

## フェーズ分割

### フェーズ1：基盤構築とコアコンポーネント開発
**期間**: 約40分

**作業内容**:
1. **環境セットアップ**
   - デフォルトテンプレートのクリーンアップ
   - Tailwind CSS導入と設定
   - カスタムカラーパレット定義
   - フォント（Noto Serif JP）設定

2. **基本構造の実装**
   - ディレクトリ構造の作成
   - App.tsxの基本レイアウト実装

3. **コアコンポーネント開発**
   - Header.tsx（ナビゲーション、ハンバーガーメニュー）
   - Hero.tsx（メインビジュアル）
   - Footer.tsx（基本情報）

**完了基準**:
- Tailwind CSSが正常に動作
- ヘッダー、ヒーロー、フッターが表示される
- レスポンシブナビゲーションが機能する

### フェーズ2：メインコンテンツとインタラクション実装
**期間**: 約50分

**作業内容**:
1. **コンテンツセクション開発**
   - About.tsx（3カラムレイアウト）

   - Access.tsx（地図埋め込み）

2. **データ層の実装**
   - menuData.tsの作成
   - 画像URLの設定（Unsplash利用）

3. **インタラクション機能**
   - スムーズスクロール実装
   - ギャラリーライトボックス機能
   - フェードインアニメーション

**完了基準**:
- 全セクションが正しく表示される
- メニューのタブ切り替えが動作
- スムーズスクロールが機能する

### フェーズ3：最終調整とビルド
**期間**: 約30分

**作業内容**:
1. **スタイリング最終調整**
   - レスポンシブデザインの微調整
   - アニメーションのタイミング調整

2. **パフォーマンス最適化**

   - ビルド成果物の動作確認

**完了基準**:
- エラーなくビルドが完了
- 全機能が正常に動作
- レスポンシブ表示が適切

## リスクと前提条件

### 前提条件
- Node.js環境が正常に動作している
- npmパッケージのインストールが可能
- インターネット接続（CDN、画像取得用）

### リスク
- パッケージの依存関係エラー → 代替パッケージを使用
- 画像読み込みの遅延 → プレースホルダー表示を実装
- ブラウザ互換性 → モダンブラウザのみサポート
