# 実装計画書：古都茶房（Koto Sabo）

## プロジェクト概要
架空のカフェ「古都茶房」の静的ウェブサイトを、React + TypeScript + Viteを使用して作成します。

## 実装計画

### 第1段階：プロジェクトのクリーンアップと基本設定

#### 1.1 既存ファイルのクリーンアップ
- デフォルトのViteテンプレートコンテンツを削除
- 不要なロゴファイル（react.svg, vite.svg）を削除
- App.css, index.cssの内容をリセット

#### 1.2 Tailwind CSSの導入
```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

#### 1.3 カスタムカラーの設定
tailwind.config.jsに以下のカラーパレットを定義：
- ブラウン系：#8B4513, #A0522D, #D2691E
- 深緑：#2F4F2F, #3C5E3C
- 生成り色：#F5F5DC, #FAF8F1

### 第2段階：コンポーネント構造の作成

#### 2.1 ディレクトリ構造
```
src/
├── components/
│   ├── Header.tsx        # ナビゲーションバー
│   ├── Hero.tsx         # メインビジュアル
│   ├── About.tsx        # カフェについて
│   ├── Menu.tsx         # メニュー一覧
│   ├── Gallery.tsx      # フォトギャラリー
│   ├── News.tsx         # お知らせ
│   ├── Access.tsx       # アクセス情報
│   ├── Contact.tsx      # お問い合わせ
│   └── Footer.tsx       # フッター
├── data/
│   └── menuData.ts      # メニューデータ
├── hooks/
│   └── useSmoothScroll.ts
└── App.tsx
```

#### 2.2 各コンポーネントの詳細

**Header.tsx**
- ロゴ「古都茶房」（明朝体）
- ナビゲーションメニュー
- モバイル用ハンバーガーメニュー
- スクロール時の背景色変化

**Hero.tsx**
- フルスクリーンの背景画像
- キャッチコピー「古都の静寂に、一杯の安らぎを。」
- スクロールを促すアニメーション

**About.tsx**
- 3カラムレイアウト（PC）
- こだわりのポイント（豆、空間、時間）
- 各要素にフェードインアニメーション

**Menu.tsx**
- カテゴリ別タブ切り替え
- メニューアイテムのグリッド表示
- 価格表示とアイテム説明

**Gallery.tsx**
- 6-9枚の画像をグリッド表示
- クリックでライトボックス表示
- レスポンシブなレイアウト

**News.tsx**
- 最新3件のお知らせをカード形式で表示
- 日付とタイトルのみ
- ホバーエフェクト

**Access.tsx**
- Google Maps埋め込み
- 営業時間：10:00 - 18:00（定休日：水曜日）
- 住所：架空の京都の住所

**Contact.tsx**
- 電話番号とメールアドレス
- シンプルなレイアウト

**Footer.tsx**
- コピーライト表記
- InstagramへのSNSリンク

### 第3段階：スタイリングとインタラクション

#### 3.1 グローバルスタイル
- Google Fontsから「Noto Serif JP」を導入
- ベースフォントサイズとline-heightの設定
- スムーズスクロールのCSS設定

#### 3.2 インタラクション機能
- **スムーズスクロール**: ナビゲーションクリック時
- **ハンバーガーメニュー**: モバイル時のメニュー開閉
- **ライトボックス**: ギャラリー画像の拡大表示
- **フェードインアニメーション**: Intersection Observer使用

### 第5段階：最終調整とビルド

#### 5.1 レスポンシブ対応
- ブレークポイント：
  - モバイル: < 640px
  - タブレット: 640px - 1024px
  - デスクトップ: > 1024px

#### 5.2 パフォーマンス最適化
- 画像の遅延読み込み（loading="lazy"）
- WebP形式への対応検討
- CSSの最小化

#### 5.3 ビルドコマンド
```bash
npm run build
```

#### 5.4 デプロイ準備
- distフォルダの確認
- index.htmlからの相対パス確認
- 静的ホスティングサービスへのアップロード準備

## 技術スタック

- **フレームワーク**: React 19.1.0
- **言語**: TypeScript 5.8.3
- **ビルドツール**: Vite 7.0.4
- **CSSフレームワーク**: Tailwind CSS
- **フォント**: Noto Serif JP (Google Fonts)
- **画像**: Unsplash (プレースホルダー)

## 成果物

1. 完全にレスポンシブ対応したシングルページアプリケーション
2. distフォルダ内の静的ファイル群
3. どの静的ホスティングサービスでも動作可能なHTMLファイル

## 注意事項

- 画像は著作権フリーのものを使用
- フォームは見た目のみで送信機能は実装しない
- Google Maps APIキーは不要（埋め込みiframe使用）
